SQL 调试

用于诊断数据查询问题的技能包。当查询返回重复事件、聚合异常或性能退化时加载。

触发条件 · 结果存在重复行 / 需要关联两个以上数据源 / 聚合结果可疑

诊断步骤

1. 先用 operation_Id 关联原始事件,再进行聚合。

2. 聚合前必须去重,否则计数会被放大。

示例

scripts/trace-analysis.tsts
// 重复事件排查
const rows = await query(`
  SELECT operation_Id, arg_max(timestamp, *)
  FROM events
  GROUP BY operation_Id`);

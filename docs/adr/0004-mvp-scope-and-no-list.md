# MVP scope: the learning loop, thin skill management, session overview — nothing else

The MVP ships the learning loop (session → knowledge → retrieval), thin skill management (markdown skill + version + domain), a session-overview report, and the Craft Agents integration (MCP server + guide skill) on one personal workspace. Explicitly **out** of MVP: skill marketplace, enterprise SSO/audit, auto memory injection, git-synced skills, per-item ACL, built-in chat UI, traffic proxy, SaaS hosting.

Why: all four value axes matter, but the loop is the only axis that exercises ingestion, storage, retrieval, and reporting in one path — it is the foundation the other axes stand on.

Consequence: positioning leads with usage intelligence and governed cross-agent context (per market research); the learning loop is expected to be solid, not differentiating.
